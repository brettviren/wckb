* Original README


- Items cover observations ("run 1234 was noisy"), documents (papers,
  slides), datasets, configurations, conditions snapshots, software,
  topic pages (synthesis), views (built HTML/PDF), policies and
  knowledge sets.
- Small content is held in the store. Large content lives in a content
  store (EOS, NFS), at a URL (Indico, arXiv) or, experimentally, in a
  DataLad dataset, all behind one data-source interface. Every rendition
  carries a SHA-256.
- Sources are append-only, enforced by the database. Corrections
  supersede. Every change and transfer is an event (=kb log=), and
  =kb item stale= shows what needs revising or rebuilding.
- Stores at every scope (project, home, group) are linked as =up=,
  =down=, =peer= or =twin= neighbors. LLMs read across them. Knowledge
  moves as knowledge sets with =kb push= and =kb pull=: applied
  atomically, or as *bundles* reviewed in the receiver's inbox by people
  and LLMs, or as pull requests in an exchange repository.
- *Assets* stand for files and file sets independently of where they
  live. Versions are identified by content, sources (directory trees,
  URLs, the store; DataLad, Indico and DocDB planned) are bound with
  their own versioning, and resolution yields one verified file set.
- Items, sets and bundles render for people (=kb show=,
  =kb bundle show=, =kb inbox show=): names, dates, links, excerpts and
  trees, with no hashes.
- Policy (CLAUDE.md instructions, skills and hooks) is named, versioned
  and enacted by =kb policy=. Autonomy (push, pull, accept, merge ...)
  is granted by the human.
- Forges (GitHub, Gitea, Forgejo), with tokens from =pass=-style
  commands.

#+begin_example
uv tool install git+<this repo>      # or: uv tool install --editable .
kb init ~/kb --scope home            # your personal store
cd ~/work/proj && kb init kb --scope project --up ~/kb   # a project store beside your code
kb new observation --title "Noisy run 1234" --summary "..." --subject detector/tpc/noise \
   --runs 1234 --by "A. Colleague" --how "verbal, collab meeting" --text "..."
kb context detector/tpc              # what the KB knows, compactly
#+end_example
