## kb add

```
Usage: kb add [OPTIONS] SOURCES...

  Add files or URLs as a new primary item (default kind: document).

    kb add slides.pdf --url https://indico.example/... --set doctype=presentation \
       --title "TPC noise update" --summary "..." --creators "A. Person" --date 2026-10-28
    kb add https://arxiv.org/pdf/2601.01234 --identifier arxiv=2601.01234 --set doctype=preprint ...
    kb add noise.csv make_noise.py --kind dataset --set format=csv --title ... --runs 1200-1300

Options:
  --kind [document|dataset|config|snapshot|software|observation]
                                  [default: document]
  --title TEXT                    Short title.
  --summary TEXT                  1-3 sentences for the next reader (an LLM); not the title again.
  --subject TEXT                  Subject path, e.g. detector/tpc/noise (repeatable).
  --tag TEXT                      Free label (repeatable).
  --runs TEXT                     Valid for runs: N or FIRST-LAST (repeatable).
  --start TEXT                    Valid from (date).
  --end TEXT                      Valid until (date).
  --status [draft|unverified|verified|disputed]
  --access [public|collaboration|group|private]
  --by TEXT                       Who asserted it (person ID or name).
  --how TEXT                      How it was asserted: 'verbal at collab meeting', 'elog 5521' ...
  --when TEXT                     When it was asserted (date).
  --creators TEXT                 Author (repeatable).
  --date TEXT                     Date of the thing itself (e.g. of a talk).
  --identifier TEXT               scheme=value: doi=, arxiv=, indico=, inspire= ...
  --evidence TEXT                 Supporting ref or URL (repeatable).
  --related TEXT                  Related ref (repeatable).
  --derived-from TEXT             Input ref, for topics and views (repeatable).
  --license TEXT
  --set TEXT                      Any field: key=value (JSON values parsed; dotted keys nest).
  --via TEXT                      Tool or session making the item (e.g. claude-code).
  --place [auto|db|cas|local|none]
                                  Where content goes: auto = in the store if small, else the content
                                  store (cas), else local-only.  [default: auto]
  --cas TEXT                      Content store (cas) to use (default: 'default').
  --url TEXT                      Canonical URL of a single local file (e.g. Indico behind SSO).
  --no-fetch                      Record URLs without downloading (no hash).
  --supersedes TEXT               This is a new version of that item.
  --extract                       Run kb extract afterwards.
  --force                         Add even if an identifier is already in this store.
  --json
  -h, --help                      Show this message and exit.
```

## kb asset bind

```
Usage: kb asset bind [OPTIONS] REF NAME

  Say that source NAME can supply asset REF, and how its versions map.

    kb asset bind as-... eos --source fs --set root=eos-group --set path=talks/2026-10-28
    kb asset bind as-... history --source fs --set root=/data/slides --versioning pattern --pattern 'v{version}'
    kb asset bind as-... indico --source url --set url=https://indico.example/.../slides.pdf

Options:
  --source TEXT                   Source type (kb asset sources lists them): fs, url, kb ...
                                  [required]
  --locator TEXT                  Source-specific identifiers as JSON, e.g. '{"root": "eos-group",
                                  "path": "talks/x"}'.
  --set TEXT                      Locator field key=value (repeatable), instead of --locator.
  --versioning [none|native|pattern|map]
                                  How the source's versions relate to the asset's.  [default: none]
  --pattern TEXT                  With pattern versioning: where versions are, e.g. '{version}' or
                                  'v{version}/slides.pdf'.
  --map TEXT                      NATIVE=LABEL (repeatable): the source's version id to the asset's
                                  label.
  --priority INTEGER              Lower is tried first.
  --note TEXT
  -h, --help                      Show this message and exit.
```
